# @aduverger/pi-rex

A planned [Pi](https://pi.dev) extension for a native mobile experience with Rex.

## Status

Name-reservation placeholder. No extension functionality is implemented yet.

## Objective

- Provide a native mobile experience for Pi through Rex on mobile.
- Explore improvements to using Rex within Pi.

## Decisions

Initial scaffold decisions, least-certain first:

- Use the scoped npm name `@aduverger/pi-rex`, matching `@aduverger/pi-ship`, rather than the unscoped `pi-rex` name.
- Make the GitHub repository public, matching the public npm package.
- Start at `0.0.1` with metadata only and an empty Pi extension manifest; defer code, dependencies, build tooling, and release automation until implementation begins.
- Use the MIT license and Alexandre Duverger authorship, matching `pi-ship`.
